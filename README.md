# LeakLock

LeakLock не пускает Mac в интернет мимо VPN. Если VPN отключился или ещё не подключился,
интернет блокируется, и сайты не увидят ваш настоящий IP. Это запасной kill switch на
случай, если встроенный в VPN-клиент не сработал.

Работает через встроенный файрвол macOS, живёт в строке меню.

## Установка

1. Скачайте `LeakLock-x.y.z.dmg` из [Releases](https://github.com/sotnikov-nk/LeakLock/releases)
   и перетащите LeakLock в «Программы».
2. Запустите. macOS заблокирует запуск, потому что приложение не подписано Apple.
   Откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите
   «Всё равно открыть». Это нужно один раз.
3. В меню щита нажмите «Установить службу…» и введите пароль администратора.
4. В «Настройках» добавьте IP своего VPN-сервера и включите «Защиту».

Интернет открывается, только когда VPN подключён и внешний IP совпадает с IP сервера.

## Что блокировать

- **Адреса из VPN** (по умолчанию). Без VPN блокируется только то, что VPN-клиент
  отправляет в туннель. Сайты, которые раздельное туннелирование пускает напрямую,
  работают и без VPN. Пока VPN ни разу не подключался, блокируется всё.
- **Весь интернет.** Без VPN не работает ничего. Выбирайте этот режим в чужих сетях
  (кафе, отель): он надёжнее.

### Раздельное туннелирование в Amnezia

В Amnezia два противоположных режима, не путайте их:

1. **«Адреса из списка должны открываться через VPN».** Без VPN LeakLock блокирует
   только сайты из списка. Добавьте в список и сервисы проверки IP: `api.ipify.org`,
   `checkip.amazonaws.com`, `icanhazip.com`, `ifconfig.me`. Иначе проверка не пройдёт
   и интернет не откроется.
2. **«Адреса из списка не должны открываться через VPN».** Без VPN LeakLock блокирует
   всё, кроме сайтов из списка.

### Несколько VPN-клиентов

Добавьте в настройки IP серверов каждого клиента и включайте их по очереди, не
одновременно.

## Что работает всегда

Даже без VPN работают AirDrop, AirPlay, повтор экрана iPhone, Sidecar и подключение к
самому VPN-серверу. В настройках можно разрешить без VPN ещё:

- **Локальную сеть:** принтеры, NAS, роутер;
- **DNS:** нужен, если сервер в конфигурации VPN указан доменом, а не IP.

## Обновление

LeakLock сам проверяет новые версии, а вручную их можно проверить кнопкой «Обновления»
в меню. Если вышла новая версия, нажмите «Обновить»: приложение скачает её из Releases,
перезапустится и попросит пароль, чтобы обновить службу.

Без VPN проверка не работает, ведь защита блокирует и GitHub.

## Если что-то не так

- **С VPN сайты не открываются.** Включите «Локальная сеть без VPN» или «DNS без VPN»:
  скорее всего, DNS указывает на роутер.
- **VPN не подключается.** Включите «DNS без VPN», если сервер указан доменом.
- **«Внешний IP не совпадает».** У сервера другой выходной IP. Когда VPN точно
  подключён, нажмите в настройках «Добавить текущий внешний IP».
- **Срочно снять блокировку без приложения:**
  ```sh
  sudo launchctl bootout system/com.leaklock.daemon
  sudo pfctl -a com.apple/050.LeakLock -F rules
  ```
- Лог: `/var/log/leaklock.log`.

## Ограничения

LeakLock защищает от случайных утечек, а не от вирусов на самом Mac. Программа,
запущенная под вашей учётной записью, может поменять его настройки или подменить
приложение. Обновления берутся только из Releases этого репозитория, но подписи Apple
у них нет.

## Удаление

«Настройки → Удалить службу…», затем удалите приложение из «Программ».

## Для разработчиков

```sh
swift test                      # тесты
scripts/build-app.sh 0.1.0      # build/LeakLock.app и DMG
```

Нужен macOS 13+ и Swift 5.9+. GitHub Actions собирает DMG на каждый PR, релиз с тегом
`vX.Y.Z` получает DMG автоматически (версия в `Sources/LeakLockCore/Version.swift`
должна совпадать с тегом).

- `Sources/LeakLockCore`: правила pf, разбор маршрутов, логика решений (с тестами).
- `Sources/leaklockd`: служба с правами root, управляет файрволом.
- `Sources/LeakLock`: приложение для строки меню.
